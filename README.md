LabData Analyzer

A Python project for analyzing laboratory test results.

Features

- Read CSV files
- Calculate statistics
- Detect out-of-range values
- Export reports to JSON

Future Improvements

- Add input data validation
- Improve error handling
- Add automated tests

Installation and usage

1. Clone the repository.
2. Make sure Python 3 is installed.
3. Place the CSV data file in the project directory.
4. Run the program:

   ```bash
   python3 main.py
5. Check the generated JSON report
